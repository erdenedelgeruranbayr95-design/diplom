> Байдал: 2026-08-07. Мобайл апп **2,171 мөр**, вэб хувилбар **22,554 мөр**.

## ЯАРАЛТАЙ — эдгээргүйгээр апп бүрэн ажиллахгүй

### 1. Git-д commit хийх

`mobile/` хавтас бүхэлдээ git-д **бүртгэгдээгүй** (`git status` → `?? mobile/`).
Компьютер эвдэрвэл бүх ажил алдагдана.

```bash
cd diplom
git add mobile/ frontend/next.config.ts frontend/package.json frontend/README.md
git commit -m "React Native мобайл апп нэмэв"
git push origin main
```

> ⚠️ Push хийвэл Vercel + Render автоматаар дахин deploy хийнэ. `frontend/`-ийн
> засварууд (порт 3001, workspace root) production-д нөлөөлөхгүй, аюулгүй.

### 2. Android утсан дээр APK суулгаж чичиргээг батлах

Дипломын **гол нотолгоо**. APK аль хэдийн бүтсэн:
`https://expo.dev/accounts/uranbayr/projects/medreh/builds/b623d610-b2b3-4fdd-b585-f39ee3faa093`

Суулгасны дараа Нүүр дэлгэцийн **Сул / Дунд / Хүчтэй** гурван товчийг дарж
эрчмийн ялгаа мэдрэгдэж байгааг шалгана.

- Мэдрэгдвэл → дипломын гол санаа батлагдсан
- "Таны утас эрчим ялгадаггүй" гэж бичвэл → тэр утасны мотор дэмждэггүй,
  өөр утсаар турших хэрэгтэй (кодын алдаа биш)

### 3. Дуунуудыг шинжлүүлж чичиргээг ажиллуулах

**Одоо ямар ч дуу чичрэхгүй.** DB-д 21 дуу бүгд `PENDING` төлөвтэй,
`beatTimestamps` хоосон. RN-д Web Audio FFT байхгүй тул зөвхөн
timestamp-driven зам ажилладаг — өгөгдөлгүй бол чичиргээ огт гарахгүй.

Хийх ажил:

1. Python worker-ийн орчин бэлдэх (`worker/`, Python 3.13 суусан байгаа)
   ```bash
   cd worker
   python -m venv venv && venv\Scripts\activate
   pip install -r requirements.txt
   ```
2. **Worker-ийн замын алдааг засах** — `worker/worker/main.py:59` дэх
   `resolve_local_path()` нь `/uploads/` замыг л ойлгодог. Seed дуунууд
   `/tracks/song-1.mp3` замтай тул одоогоор ажиллахгүй.
3. Redis дараалалд (`haptic:jobs`) ажил гараар нэмэх — backend нь зөвхөн
   upload үед л job үүсгэдэг, одоо байгаа дуунуудад үүсгэдэггүй.
4. ffmpeg суулгах (заавал биш — HLS хөрвүүлэлт алгасагдана, код зохицуулдаг)

### 4. Дутуу аудио файлууд

DB-д **21 дуу**, гэтэл `frontend/public/tracks/`-д ердөө **6 файл**
(song-1, 2, 3, 4, 8, 9). Үлдсэн 15 нь байхгүй файл руу заасан бичлэг.

Сонголт: (а) дутуу mp3-уудыг нэмэх, (б) DB-ээс тэр мөрүүдийг цэвэрлэх.

## ДАРААГИЙН ЭЭЛЖ — дэлгэц нэмэх

Вэбийн 17 дэлгэцээс **5 нь** мобайлд хийгдсэн (хялбаршуулсан хэлбэрээр).

### 5. Дэлгэрэнгүй (`DetailView`)

Дууны бүрэн мэдээлэл — тайлбар, үг, гаралтын он, ижил дуучны бусад дуу.
Backend бэлэн: `GET /songs/:id`, `GET /songs/:id/more-by-artist`.

### 6. Дуучин (`ArtistView`)

`GET /artists`, `GET /artists/:id`, `GET /artists/:id/songs`.
Вэб дээрх "Алдартай дуучид" эгнээ ч мөн хийгдээгүй.

### 7. Сонссон түүхийн ДЭЛГЭЦ (`HistoryView`)

Бичих тал нь **хийгдсэн** — тоглуулагч 5 секундээс дээш сонссон дуг бүрийг
`POST /history`-оор бүртгэдэг болсон (бодитоор шалгасан: `total=123с`).
Статистик дэлгэц одоо жинхэнэ өгөгдөл харуулна.

"Чичиргээ" тоолуур ч мөн **засагдсан** — `vibrations` талбарыг `CreateHistoryDto`-д
нээж, `history.service.ts`-д дамжуулав. Тоглуулагч нь чичиргээ БОДИТООР
ажилласан үед л (товч асаалттай **ба** дуу цохилтын өгөгдөлтэй) `true` илгээнэ.

Бодитоор шалгасан: `vibrations=true` → `vib=1`, `false` → тоологдохгүй.

Дутуу: **харах дэлгэц** (`GET /history`, `DELETE /history/:id`) —
"Сонссон түүх" жагсаалт, мөр устгах.

### 8. Жагсаалт бүрэн болгох (`PlaylistsView`)

Одоо зөвхөн **харах** боломжтой. Дутуу: үүсгэх, нэр солих, устгах,
дуу нэмэх/хасах. API бүгд бэлэн (`POST/PATCH/DELETE /playlists`).

### 9. Төхөөрөмж (`DevicesView`)

Чичиргээний калибровк, холбогдсон төхөөрөмж. BLE хантааз нэмэх бол
`react-native-ble-plx` хэрэгтэй (вэб дээр Web Bluetooth ашигладаг).

### 10. Захиалга (`BillingView`)

`GET /me/payments`, `PATCH /me/subscription`. QPay/SocialPay холболт.

### 11. Тусламж (`HelpView`)

Статик агуулга, хамгийн хялбар.

### 12. Удирдлагын самбарууд

`TherapistView` · `ParentView` · `ProgressView` · `UploadSongView` · `AnalysisView`

> 💡 Эдгээрийг гар утсанд **хийхгүй байхыг зөвлөж байна**. Эмч, эцэг эх, админ
> нар компьютерээс ордог. Вэб дээр үлдээвэл ажил ~40% багасна.

## ЛОГИКИЙН ДАВХАРГА

Порт хийгдсэн байдал:

| Модуль | Вэб | Мобайл | Дутуу |
|---|---|---|---|
| `lib/api` | 584 | 243 | ~340 мөр (playlists CRUD, therapy, admin, payments) |
| `lib/haptics` | 304 | 139 | `GamepadDevice`, `BleVestDevice` |
| `lib/player` | 1,981 | 122 | **1,859 мөр** |
| `lib/audio` | 446 | 44 | **402 мөр** |
| `lib/socket` | 181 | 0 | **181 мөр — бүхэлдээ** |

### 13. Санал болгох алгоритм (`lib/player/recommendations.ts`)

Цэвэр TypeScript, DOM-оос хамааралгүй → бараг хэвээр шилжинэ.
Нүүр дэлгэцэд "Танд санал болгож байна" эгнээ нэмнэ.

### 14. Визуалайзер

Вэб дээр Canvas + `requestAnimationFrame`-ээр хийгдсэн — RN-д **бүхэлдээ дахин
бичих** шаардлагатай. `react-native-skia` эсвэл `react-native-svg` + Reanimated.

⚠️ Гэхдээ RN-д спектр (FFT) авах арга байхгүй тул вэбтэй ижил амьд визуал
хийх боломжгүй. `bandEnergies` (backend-ийн шинжилгээ) дээр тулгуурлана.

### 15. QR хослуулалт (`lib/socket`)

Компьютер дээр тоглуулж утсаар чичрэх горим. Socket.io клиент нэмэх.
`socket.io-client` аль хэдийн суусан.

Сүлжээгүй үед юу болохыг огт бодоогүй. Одоо зүгээр л алдаа харуулна.

### 18. Тоглуулагчийн дараалал

Одоо ⏮/⏭ нь бүх дууны жагсаалтаар явна. Дутуу: давтах, холих,
дараалал үүсгэх.

`modules/haptic-waveform/ios/HapticWaveformModule.swift` бичигдсэн ч
**хэзээ ч compile хийгдээгүй, туршигдаагүй**.

Шаардлага: Apple Developer Program (**жилд $99**), утас бүрийн UDID бүртгэх.
Mac шаардлагагүй (EAS үүлэн дээр build хийнэ).
